## Question

首发 MVP 到底包含什么、验收怎么算过？哪些模式（朋友房 / 公共匹配 / 教学）、哪些人数（4–12 全开还是先 4–8）、哪些卡与变体、哪些平台、哪些非功能指标（12 人并发、重连成功率、泄漏零、低端机帧率）？

## 建议（可被推翻）

朋友房 4–12 全人数、完整基础牌表、无变体开关；H5 竖屏；12 人房 20 局 soak、重连 < 5 秒、零泄漏、红米级低端机 30fps；公共匹配与教学留二期。

## Answer

**结论（4B）：朋友房 4–12 全开；6–8 人优先验收，12 人压测作为发布门禁；不做公共匹配与教学。**

- 范围：H5/PWA 竖屏；游客昵称；6 位房码；完整基础 59 张 + 15 身份 + 3 试炼；无变体；外置语音 + 快捷语 + 房内文字；全屏夜晚；服务端权威；断线重连。
- 人数：4–12 都可开局；6–8 人做完整功能验收（10 局无阻断）；12 人做 20 局 soak，作为发布门禁。
- 指标：零隐藏信息泄漏；重连 <5 秒；p95 操作延迟 <300ms；低端机 30fps；单局 20–40 分钟；iOS Safari + Android Chrome 各一台真机走通。
- 发布门禁：规则一致性测试 100%；12 人压测通过；投影泄漏扫描通过；无 P0/P1 缺陷。
- 二期：公共匹配、账号、教学/bot、观战/回放、内建语音、小程序、商业化。
- 落地：见 [SPEC.md](../SPEC.md) §7、§8。
