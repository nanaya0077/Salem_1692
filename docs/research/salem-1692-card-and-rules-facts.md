- **信徒**：其他玩家不能对你打出红卡；嫁祸、医生等“移动红卡”的效果不受此限制。

- **开局可配**：女巫数与每人身份卡数都可覆盖；身份卡总数 = 人数 × 每人数量，必须 ≥ 女巫数 + 1（警长）。

## 0. 结论

- 基础游戏共 **59 张出牌**：红 41、绿 11、蓝 5、黑 2；另有 15 张身份牌、按人数抽取的试炼牌，以及 1 枚木槌。Bless / Shilling 是扩展/促销牌，不进入基础 59。
- 4–12 人；中文旧版默认每人身份卡数为 5 / 5 / 5 / 5 / 5 / 5 / 3 / 3 / 3（对应 4–12 人）；女巫数默认为 1 / 1 / 2 / 2 / 2 / 1 / 2 / 2 / 2（对应 4–12 人，9 人为 1），可在开局前覆盖。
  - 第二版对照：9 人为 2 女巫；每人身份卡数为 5 / 5 / 5 / 5 / 4 / 4 / 3 / 3 / 3。两版在 8/9 人处不同，当前实现按中文旧版。
- 第二版与第 15 版在四个地方会改变玩法：多张女巫牌、两张情侣给同一人、Thomas/信徒的指控数学、死亡时是否必须承认“曾经是女巫”。当前默认中文旧版；第二版/第 15 版保留作差异参考，不混在一起。
- 数字化最容易做错的三件事：
  1. **阵营是“曾经持有过女巫牌”**，不是“当前手里有女巫牌”。女巫牌被换走仍然是女巫。
  2. **红牌不跨次累计**；达到门槛只翻一张，多余点数丢弃。
  3. **夜晚的免疫与媒人连锁是分开的**：木槌/认罪/庇护让被夜杀者不死，但媒人连锁仍可能杀死其搭档。

## 3. 基础牌 59 张

### 3.1 红牌 41 张

红牌放在目标玩家面前，不绑定某一张试炼牌。达到门槛后，由**打出达到门槛那张牌的玩家**选择目标一张未揭示试炼牌翻开；然后把目标面前所有红牌弃掉。多余点数不结转。

| 牌 | 英文 | 数量 | 点数 | 规则 | 数字边界 |
|---|---|---:|---:|---|---|
| 指控 | Accusation | 35 | 1 | 对另一玩家打出，点数 +1 | 最基础的红牌；不能打自己 |
| 证据 | Evidence | 5 | 3 | 对另一玩家打出，点数 +3 | Cotton Mather 面前只算 1；Martha 继承 Cotton 后 Cotton 死亡，已在其面前证据立刻变 3 |
| 目击 | Witness | 1 | 7 | 对另一玩家打出，点数 +7 | 单独一张即可触发（George 门槛 8；中文旧版信徒不再提高门槛，改为红卡免疫） |

**门槛表（第二版对照）**

| 防守方 | 普通攻击者 | Thomas Danforth 攻击 |
|---|---:|---:|
| 普通 | 7 | 6 |
| George Burroughs | 8 | 7 |
| 有 Piety | 14 | 12（第 15 版补充） |
| George + Piety | 16 | 14（第 15 版补充） |

Thomas 的卡面是“第六（或第七）张指控时可选翻一张”，不是“第十张”；早期 OCR 把 SEVENTH 误读成 TENTH。第二版按“6 点可选、放弃则 7 点正常触发”实现。第 15 版对 Piety 的 12/14 点作为变体开关。

**红牌结算顺序**

1. 把红牌放到目标面前。
2. 重新计算目标当前红牌总点数。
3. 若达到门槛，触发一次揭示；只翻一张。
4. 若仍达到门槛（例如 6 点时打出 Evidence 到 9），继续下一次揭示；每次独立选择、独立触发 Rebecca / Abigail / Anne 等。
5. 每次揭示后把目标面前所有红牌弃掉，再检查是否还有点数。**不能把多余点数带到下一张试炼牌。**

      -> turn_end（Anne 触发）
      -> next_turn（顺时针下一个存活玩家）
      -> night（抽到 Night 时插入）
      -> game_over

### 5.1 回合开始

1. 若当前玩家有 Stocks：跳过本回合，弃 1 张 Stocks，进入下一个玩家。多张则连续跳过多个回合。
2. 若当前玩家是 Tituba 且本局未用能力：给出“重排牌堆”选项，限时；不用则正常开始。
3. 当前玩家选择：抽 2 张，或打出至少 1 张牌。

### 5.2 抽牌

- 逐张抽。抽到黑牌立刻公开并结算，黑牌算作两张中的一张。
- 抽到 Night：立刻进入夜晚；夜晚结束后，若还有第二张没抽，从重组的牌堆继续抽。
- 牌堆只剩 1 张且是 Night：先夜晚，再抽第二张（第 15 版明确）。
- 牌堆为空且没有 Night：这是异常状态；洗弃牌堆重建，并记录告警。

### 5.3 出牌

- 可以打出任意多张，逐张结算；每张结算完再选下一张。
- 不能打自己；不能打出直接作用于自己的效果（第一法则）。
- 只剩两名存活玩家时，Robbery / 替罪羊不能打，按蓝牌留在手里（第二版明确“当作蓝牌”）。
- 黑牌不能从手里打出；黑牌只在抽到时结算。

### 5.4 回合结束

- 触发 Anne 的“本回合每翻一张试炼牌抽 2”。
- 检查手牌上限？基础规则没有手牌上限；不实现。
- 传给顺时针下一个存活玩家。

## 6. 结算原语

### 6.1 翻试炼牌

    revealTrial(target, chooser, source):
      card = target 的某张未揭示试炼牌（由 chooser 选；若规则没指定则由 target 选）
      card.revealed = true
      log
      if card == Witch:
          if edition == 2nd: kill(target, "witch-revealed")   # 并揭示其余女巫牌
          else if target 还有未揭示 Witch: 公开告知，继续存活
          else: kill(target, "witch-revealed")
      if target 所有试炼牌都已揭示: kill(target, "all-trials-revealed")
      if card == Constable: 更新 Constable 身份（可能变成/失去治安官）
      checkWin()

- 第二版多张女巫：一张揭示即死，死亡时揭示其余女巫牌。第 15 版：还有未揭示女巫则存活并告知。
- 翻到 Constable 不死亡；只是身份变化。若 Constable 是女巫，仍是“邪恶治安官”。
- 翻牌后若目标死亡，按 6.2 结算。

### 6.2 死亡

    kill(player, cause):
      if not alive: return
      alive = false
      reveal all remaining tryals
      if edition == 2nd: 公开“是否曾经拥有女巫牌”
      # John Proctor 在弃手牌前触发
      if another alive John Proctor: John 选至多 3 张手牌拿走
      discard hand + all front cards（红/蓝/绿）
      if player held Black Cat: Black Cat 进弃牌堆
      # 媒人连锁
      if player has Matchmaker:
          partner = 另一个 Matchmaker 持有者
          if partner alive: kill(partner, "matchmaker")
      checkWin()
      # 死亡玩家的回合立即结束

顺序要点：
1. John Proctor 的“选 3 张”发生在死者手牌弃掉之前。
2. 面前的红/蓝/绿全部弃掉；Stocks 也弃掉。
3. 黑猫若在死者面前，进弃牌堆，之后夜晚洗牌可能再抽到。
4. 媒人连锁在主要死亡结算后；每次死亡都检查胜负。
5. 第二版要求死亡时如实承认是否曾为女巫；数字端服务端本来就知道，UI 按版本决定是否公开。

### 6.3 胜负

- **平民胜**：所有女巫试炼牌都被揭示（包括死亡时揭示的）。不要求杀死所有女巫。
- **女巫胜**：所有存活玩家都曾经持有过女巫牌；或最后一名平民变成女巫（该玩家输）。
- 阵营是**曾经持有**，不是当前持有：
  - 收到女巫牌 → 立刻成为女巫。
  - 失去女巫牌 → 仍然是女巫，夜晚仍参与女巫行动。
- 每次翻牌、死亡、阴谋换牌、阵营变化后都要检查胜负。
- 同时结算：按“主要死亡 → 检查胜负 → 媒人搭档死亡 → 检查胜负”的顺序；第二版明确媒人搭档“晚半秒”死，用来判阵营。第 15 版“只死目标”作为变体开关。

### 6.4 触发顺序

单张牌结算的固定顺序：

1. 验证目标与合法性。
2. 弃牌/放置牌（绿牌进弃牌堆，红/蓝牌进目标面前）。
3. 立即效果（移动、弃牌、转手）。
4. 重算红牌门槛，逐张翻试炼牌。
5. 结算死亡。
6. 死亡触发（John Proctor、媒人、胜负）。
7. 延迟触发（Anne 回合结束、Rebecca 每次翻牌）。

任何一步触发胜负就停止后续结算，除了“已经发生的死亡”仍要完成揭示。

## 7. 夜晚

1. **女巫选杀**：所有女巫（曾经持有过女巫牌且存活）选一个目标；可以选女巫自己（做局）。数字端需要女巫内部协商机制；规则要求她们达成一个目标。W-05 决定用私聊+投票还是队长制；W-01 只记录“必须是一个目标”。
2. **治安官放木槌**：当前持有未揭示 Constable 试炼牌的玩家选一名其他玩家（不能自己）。若 Constable 是女巫，可以故意救错人。没有 Constable 则跳过。
3. **认罪窗口**：任意存活玩家可翻自己一张试炼牌，获得当夜免疫。翻到女巫牌是否立刻死，规则书没写清；本票裁决：**认罪只免疫夜杀，不免疫“翻到女巫牌”的死亡**。这是 D 级裁决，W-07 要写测试。
4. **结算**：公开夜杀目标。目标不死，如果：
   - 被治安官给了木槌；或
   - 当夜认罪；或
   - 面前有 Asylum。
   否则目标死亡。目标死亡后触发媒人连锁、死亡能力、胜负。
5. **收尾**：Night 放一边；洗牌堆+弃牌堆；切半；把 Night 洗进下半堆；放回桌面。继续游戏。

夜晚的“目标”在结算前是隐藏信息；木槌和认罪在结算时公开。
