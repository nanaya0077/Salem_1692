# 女巫镇 · 竖屏牌桌原型

这是 W-08 的可点原型，用来回答“6 寸竖屏上，4–12 人牌桌怎么排、自己始终看到什么、出牌与选目标怎么点”。它是静态 HTML，不接服务端；界面逻辑是简化演示，真正的规则引擎在 [`packages/rules`](../packages/rules)。

> 传染阶段（#59）另有独立原型：[`conspiracy.html`](conspiracy.html)，已选抽屉形态；问题、结论与 motion/audio 接口核对见 [`conspiracy-notes.md`](conspiracy-notes.md)。

## 运行

```bash
cd prototype
python -m http.server 8099
# 打开 http://127.0.0.1:8099/table.html
```

也可直接双击 `table.html`（无外部依赖、无构建）。

## URL 参数

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `variant` | `ring` / `strip` / `list` | `ring` | 三种对手区布局，也可在底部切换 |
| `count` | `4`–`12` | `12` | 玩家人数；4 人时对手 3 席，环形自动变成三角 |
| `autostart` | `0` / `1` | `0` | `1` 时跳过开局配置，直接按默认配比开局（截图/冒烟测试用） |

例：`table.html?variant=list&count=8`、`table.html?count=12&autostart=1`

## 三种布局

- **环形 ring（默认）**：所有对手围绕中央牌堆均匀分布；4 人时三角、8 人时椭圆、12 人时全环。信息密度最高，最像实体桌。
- **卡带 strip**：4 列网格，11 个对手排成 3 行；扫视快，适合“谁快死了”的快速判断，但空间感弱。
- **列表 list**：3 列紧凑卡，名字/指控/试炼点对齐；最省纵向空间，适合小屏或网络差时降级。

## 首屏固定信息

- 顶部：房间号、局数/天数、回合倒计时、菜单。
- 公共条：牌堆、弃牌、夜晚数、存活人数、当前玩家。
- 中央：对手区（布局可切换）。
- 底部“我”区：身份与能力、按开局配置的 2–8 张身份卡、7 点指控条、手牌横向滚动。
- 操作栏：抽 2 张、结束回合、夜晚演示。
- 底部切换：布局 / 人数 / 女巫-平民视角；菜单可重新打开开局配置。

设计取舍：手牌和身份卡始终在首屏，不藏进抽屉；对手信息按“指控数 > 身份卡 > 蓝卡点”排序，因为玩家最常判断的是“离翻牌还有多远”。

## 可交互路径

0. 首屏打开“开局配置”：选 4–12 人、女巫数、每人身份卡数；实时显示“身份卡总数 = 女巫 + 警长 + 平民”，确认后发牌。
1. 点一张手牌（高亮）→ 点一名对手（或自己，若牌允许）→ 结算并写入日志。
2. 指控/证据/目击：累加指控点；达到门槛自动翻一张身份卡；翻到女巫牌或三张翻完即死亡。
3. 辩护：减 3 点指控；拘留：目标跳过下回合；纵火：弃手牌（莎拉·古德免疫并丢弃该卡）；诅咒：弃一张蓝卡；蓝卡：放到目标面前。
   信徒在场时，红卡不能打给持有者；嫁祸/医生等移动红卡的效果不受限。
4. 嫁祸/抢劫：先选来源，再选去向；嫁祸把来源面前所有出牌移到去向并重算来源指控；抢劫来源是莎拉·古德时无效并丢弃。
5. 抽 2 张、结束回合：切换当前玩家；拘留会跳过。
6. 夜晚演示：女巫选杀 → 警长锤子 → 自首窗口 → 天亮结算；非女巫视角看不到女巫名单。
7. 视角切换：女巫/平民，验证隐藏信息投影的界面差异。
8. 点头像打开玩家详情：存活状态、指控/门槛、手牌数、身份能力。

## 已覆盖的规则原语

- 4–12 人身份卡配比与角色卡数量；身份卡=按人数暗置 2–8 张，默认 4–9 人 5 张、10–12 人 3 张；女巫数可配。
- 指控门槛（7 点；乔治 8 点；科顿对证据只算 1 点）。
- 翻牌、死亡、平民/女巫胜负判定（原型内简化）。
- 红卡累计、蓝卡常驻、绿卡弃置。
- 夜晚四步、锤子、自首、避难（Asylum）免夜杀。
- 嫁祸移动红卡、抢劫转手牌、拘留跳过、纵火弃手牌、诅咒弃蓝卡。
- 信徒：红卡不能打给持有者；莎拉·古德：抢劫/纵火无效并丢弃。

## 明确不做

- 不接服务端、不做真实多人同步、不做断线重连。
- 不做拖拽出牌、不做动画/音效、不做语音。
- 不做账号、匹配、观战、回放、教学、bot。
- 不做横屏、平板、桌面布局；不做无障碍与国际化。
- 不是最终视觉：卡面用 CSS 占位，中文卡面见 `assets/source/README.md` 与 W-10。
